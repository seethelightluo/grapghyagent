STEP 1 拉取与环境

克隆仓库并完成环境配置

请从 https://github.com/seethelightluo/grapghyagent 克隆仓库，并进入项目根目录。 检查本机 Python 版本（建议 >= 3.10），然后在 program 目录创建虚拟环境并安装依赖。 依赖安装请优先遵循 program/README.md 的说明（如 requirements.txt 或 pyproject.toml）。 完成后请列出可用的启动/运行命令与入口脚本，并说明每个命令的用途。
STEP 2 填写密钥

配置 program/.env

现在我们来配置本地环境。请打开 program/.env，将我提供的 API Key 填入对应字段（例如 ANTHROPIC_API_KEY、OPENAI_API_KEY）。 如果我还提供了代理或 Base URL（例如 ANTHROPIC_BASE_URL），也请一起填写。 请注意：.env 只用于本地运行，不要提交到仓库。完成后仅回复“已配置完成”。

结合 evidence_chain 解决问题

请先阅读 program/.cheetahclaws/skills/evidence_chain/SKILL.md，提炼它的输入、输出与使用约束。 然后使用 program 内置的 agent 或 CLI（遵循 program/README.md 的运行方式）来回答我的问题： 【我的问题】：{在这里替换为你的具体问题} 输出要求： 1) 给出图式拆分（节点、依赖、并行关系） 2) 每个节点的输入/输出与 Gate 3) 最终答案 + 关键证据/数据来源摘要
